07 · Index Construction

6 — Index Construction

A transparent, reproducible aggregation — route relatives combined by their weights into a single national number.

Route-level price relative
Price Relative = Current Representative FareReference Fare  ×  100
National Airfare Index
APIx = Σ (Route Weight × Route Index)
Route fares Route weights → Weighted aggregation → APIx
BASE = 100

An index level expresses airfare movement relative to a reference period, not an absolute ticket price. Route-level relatives are rebased so the reference scrape window equals 100; each later window is measured against it. Because weighting and rebasing are reproducible, any consumer of the API can reconstruct the number.

Experimental / high-frequency airfare index designed to complement official CPI measurement — not the CPI itself.
